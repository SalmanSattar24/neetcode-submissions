# Reviewer guide

Start with one problem folder and compare its numbered submissions. The structure makes iteration visible without rewriting the underlying history.

A useful review asks what changed in correctness reasoning, complexity or edge-case handling. Do not infer those properties solely from revision numbers. Judge-provided types and constraints may be required to run a file.

The generated index inventories checked-in source paths, not pass/fail outcomes. This is algorithm practice supporting a broader engineering portfolio, not evidence of a deployed system or a new benchmark.
