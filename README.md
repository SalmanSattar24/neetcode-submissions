# NeetCode Practice Submissions

An automatically synced archive of coding-practice submissions, organized by topic, problem folder and numbered revision. It complements the [older LeetCode export](https://github.com/SalmanSattar24/LeetCode), rather than representing a separate deployed product.

## Navigate the code

[Full submission index](docs/SOLUTIONS_INDEX.md) · [Reviewer guide](docs/EMPLOYER_GUIDE.md)

```text
Data Structures & Algorithms/
  problem-slug/
    submission-0.py
    submission-1.py
    ...
```

For example, inspect [binary search](Data%20Structures%20%26%20Algorithms/binary-search/submission-0.py), [island traversal](Data%20Structures%20%26%20Algorithms/count-number-of-islands/submission-0.py) or [linked-list merging](Data%20Structures%20%26%20Algorithms/merge-two-sorted-linked-lists/submission-0.cpp).

## How to interpret revisions

Numbered submissions preserve iteration. A later number is not a documented correctness proof or an automatic recommendation over an earlier approach. This overview does not claim that every synced file was accepted, optimal or independently tested.

Platform solutions can depend on provided class definitions, inputs, imports and constraints. Read them in the original problem context; they are not standalone applications.

## For an employer

Use selected examples to discuss data structures, invariants, edge cases and algorithmic tradeoffs. For system design, deployment, ML evaluation and integration work, see the larger projects linked from the GitHub profile instead.
